## Language / voice

**Primary line:** Train Like An NFL Athlete  
**Support:** Speed, strength, agility, and confidence training for young athletes ready to level up.  
**Footer:** Train with intention. Improve your game.  
**CTA:** Book a Session  

Tone: elite, proof-backed (NFL / TCU / Combine), family-friendly, outcome-focused. Phrases in market: `#DawgWork`, “Dream Chasers Only”.

## UI patterns

- Primary buttons: cyan fill, dark text, angled clip-path, soft cyan glow
- Outline buttons: white border → cyan on hover
- Section rhythm: cyan eyebrow → Bebas title → one short support line
- Prefer sharp corners; avoid soft pastel / purple gradient “AI sports app” looks

See `brand.ts` for machine-readable constants and `tokens.css` for CSS variables.
